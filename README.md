# LUMI Shop — UI Demo

Giao diện shop sản phẩm số, hiện tại chỉ là frontend demo với các nút giả.

## Chạy local
Mở `index.html` trực tiếp trên trình duyệt, hoặc dùng Live Server trong VS Code.

## Deploy Vercel
Có thể import repo GitHub chứa thư mục này vào Vercel. Không cần build command vì đây là static site.

## Giai đoạn tiếp theo
- Database sản phẩm/danh mục
- Trang chi tiết sản phẩm
- Giỏ hàng thật
- Đăng ký/đăng nhập
- Thanh toán
- Quản lý đơn hàng
- Admin panel
